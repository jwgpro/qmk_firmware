# devotion_kb_thinkpad_kb_only

This is QMK firmware for the `kb-only` variant of the STM32F401-based [devotion-kb-thinkpad](https://github.com/jwgpro/devotion-kb-thinkpad) controller.

VIA is enabled and works, but I have to sideload a JSON to remap keys, and I haven't put a real one together yet.

Thanks to the following people for their projects, which I used as references:

- [Frank Adams](https://github.com/thedalles77) - [Pico_T61_Keyboard](https://github.com/thedalles77/USB_Laptop_Keyboard_Controller/tree/master/Example_Keyboards/Pico_T61_Keyboard)
- [Jiri Panacek](http://www.panacek.net/) - [t61-qmk-usb-keyboard](https://forum.thinkpads.com/viewtopic.php?f=80&t=134293&p=867075)
